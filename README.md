# Jarvis AI

A desktop AI assistant built with Python.

## Features

- ✅ Voice activation ("Hey Jarvis")
- ✅ Screenshot capture
- 🚧 Screen recording
- 🚧 Text-to-Speech
- 🚧 AI-powered command understanding

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
